Integrationer – vi kopplar ihop era system via API

Kela group bygger integrationer för företag som vill koppla ihop sina system via API: affärssystem, bokföring, schema, betalning, e-post, sms och kalender. Ni behåller det ni redan använder, till exempel Fortnox, Visma, Timewave eller Tengella, och slipper skriva in samma uppgifter flera gånger. Det ger mindre administration och färre fel.

Boka möte → Få en offert

Vad är en systemintegration?

En systemintegration är en koppling som låter två program skicka information till varandra automatiskt, oftast via ett API (ett gränssnitt som system använder för att prata med varandra). Då behöver ingen skriva in samma kund, bokning eller faktura två gånger.

Kela group bygger integrationer mellan era befintliga system och våra egna moduler – och mellan era system inbördes. Allt vi säljer kör vi själva i egna verksamheter, bland annat städbolaget Stodona, så kopplingarna är byggda för vardagen, inte för en demo.

  • Ni behåller ert affärssystem – inget byte, ingen ny inlärning för hela företaget.
  • Uppgifter skrivs in en gång och finns sedan överallt där de behövs.
  • Färre fel, färre dubbelregistreringar och mindre manuell administration.

Använder ni ett annat system?

Listan ovan är de system vi oftast möter. Andra system med ett öppet API går också att koppla – berätta vad ni använder så kontrollerar vi vilka uppgifter som går att hämta och skicka.

Vilka Kela-produkter använder integrationerna?

  • Bokis – bokningar med pris, restid och automatisk schemaläggning i ert system.
  • Chattis – AI-chattbot som bokar om, avbokar och svarar på fakturafrågor med data från affärssystemet.
  • Påminnis – automatiska påminnelser om obetalda fakturor, utifrån betalstatus.
  • Headof – dashboard live mot affärssystemet med försäljning, timmar och nyckeltal.
  • Personalapp och Kundapp – appar som visar och uppdaterar samma data som ert system.
  • Feedis – sms-betyg som skickas efter utfört uppdrag.

Se alla moduler under Produkter, eller läs mer om hur vi bygger skräddarsydda system.

Vanliga frågor

Bra att veta om integrationer

Har ni en fråga som inte finns här? Hör av er så svarar vi inom 24 timmar på vardagar.

Vilka system kan Kela group integrera med?
Vi kopplar ihop system som har ett öppet API – till exempel affärssystem som Timewave och Tengella, ekonomiprogram som Fortnox och Visma, betallösningar, e-post- och sms-tjänster och kalendrar. Har ert system ett API går det i regel att koppla. Vi kontrollerar det alltid i kartläggningen.
Måste vi byta affärssystem för att använda Kelas moduler?
Nej. Hela poängen är att ni behåller det ni redan har. Våra moduler, till exempel Bokis och Headof, kopplas via API till ert befintliga system så att allt börjar hänga ihop.
Vad kostar en integration?
Det beror på hur många system och flöden som ska kopplas ihop. Ni får alltid en offert efter era behov – kostnadsfritt och utan förpliktelse. Delbetalning på upp till 2–3 år är möjlig. Få en offert.
Är Kela group officiell partner till Fortnox, Visma, Timewave eller Tengella?
Nej. Vi bygger integrationer mot systemens API:er åt våra kunder, men vi är inte officiell partner till någon av leverantörerna.
Vad händer om det andra systemet ändrar sitt API?
Integrationer behöver skötas över tid. Vi kan ta hand om löpande underhåll, så att kopplingen hålls uppdaterad när ett system ändras.

Fortnox, Visma, Timewave och Tengella är varumärken som tillhör respektive ägare. Kela group är inte officiell partner till någon av leverantörerna.
