Skräddarsytt system eller standardsystem?

Ett standardsystem passar när era processer liknar alla andras, medan ett skräddarsytt system lönar sig när arbetssättet är unikt eller när manuellt dubbelarbete kostar mycket. För många företag är mellanvägen bäst: behåll standardsystemet och bygg egna moduler via API. Kela group arbetar så, bland annat i städbolaget Stodona.

Av Mikaela Wigert · Publicerad 25 oktober 2026 · 6 min läsning

Frågan om att köpa ett färdigt system eller bygga eget dyker upp i nästan varje växande företag. Ofta ställs den som ett antingen–eller. Här går vi igenom båda alternativen – och varför svaret allt oftare är både och.

Kort sagt

  • Standardsystem: beprövat och snabbt i gång, men ni anpassar er efter systemet.
  • Skräddarsytt system: följer ert arbetssätt, men kräver ett utvecklingsprojekt.
  • Mellanvägen: behåll standardsystemet som grund och bygg det som saknas som egna moduler via API.
  • Stodona sänkte sina kostnader med ungefär 565 000 kr per år på det sättet.

Vad är skillnaden mellan ett standardsystem och ett skräddarsytt system?

Ett standardsystem är en färdig programvara som många företag använder på samma sätt, till exempel ett affärssystem, ett ekonomisystem eller ett schemasystem. Ni betalar oftast en licens eller månadsavgift, och leverantören står för utveckling och drift.

Ett skräddarsytt system är byggt för just er verksamhet. Det följer era processer, era regler och era begrepp – i stället för att ni anpassar er efter programvaran. Läs mer om hur vi bygger system.

För- och nackdelar med standardsystem

Fördelar

  • Snabbt i gång – systemet finns redan
  • Beprövat av många användare
  • Leverantören sköter uppdateringar, säkerhet och drift
  • Lätt att hitta personal och konsulter som kan systemet

Nackdelar

  • Ni anpassar arbetssättet efter systemet, inte tvärtom
  • Det som skiljer er från konkurrenterna går ofta inte att bygga in
  • Luckor fylls med kalkylblad, extra verktyg och manuellt arbete
  • Avgifterna växer ofta med antal användare och tillval
  • Ni är beroende av leverantörens prioriteringar

För- och nackdelar med skräddarsytt system

Fördelar

  • Följer exakt hur ni arbetar
  • Kan automatisera det som är unikt för er
  • Ni äger lösningen och bestämmer över utvecklingen
  • Ersätter flera separata verktyg med ett flöde

Nackdelar

  • Kräver ett utvecklingsprojekt innan det är i drift
  • Någon måste ansvara för drift, underhåll och vidareutveckling
  • Att bygga om sådant som standardsystem redan gör bra är sällan lönsamt

Mellanvägen: standardsystem + egna moduler via API

De flesta företag behöver inte välja. Ekonomi, lön och schema fungerar ofta bra i ett standardsystem. Det som skaver är flödena runt omkring: hur kunden bokar, hur personalen rapporterar, hur fakturor följs upp och hur kunderna får svar.

Mellanvägen innebär att ni behåller standardsystemet som grund och bygger det som saknas som egna moduler. Modulerna kopplas via API, så att data flödar åt båda hållen och ingen behöver föra över något för hand.

  • Standardsystemet är fortfarande ”sanningen” för kunder, schema och fakturor
  • Modulerna gör det som är unikt för er – till exempel bokning, kundtjänst eller uppföljning
  • Ni bygger stegvis och börjar där vinsten är störst

Kela group har färdiga moduler i skarp drift som kopplas via API till affärssystem som Timewave, Tengella, Fortnox och Visma – till exempel bokningssystemet Bokis, AI-chattboten Chattis, påminnelsesystemet Påminnis och dashboarden Headof. Se alla på sidan Produkter. Behöver ni ett eget CRM eller affärssystem kring kund och affär, läs om affärssystem och CRM.

Exempel: så gjorde Stodona

Allt Kela group säljer kör vi själva i våra egna verksamheter, bland annat i städbolaget Stodona AB. Där har vi byggt egna system, integrationer och automationer kopplade till affärssystemet. Resultatet:

  • Ungefär 565 000 kr lägre kostnad per år – den löpande kostnaden gick från cirka 52 000 kr till 5 000 kr i månaden
  • Från fyra personer till en i administrationen
  • Tre heltidstjänster frigjorda till annat arbete

Läs mer om projektet bland våra case.

Vanliga misstag när man väljer system

  • Att jämföra bara licenskostnaden. Räkna också med tiden som går åt till manuellt arbete, dubbelregistrering och extra verktyg runt systemet.
  • Att bygga om allt på en gång. Ett stort systembyte är riskabelt. Att bygga modul för modul ger resultat tidigare och mindre risk.
  • Att bygga det som redan finns. Bokföring och lön är sällan det som gör er unika – lägg utvecklingen där den gör skillnad.
  • Att glömma datan. Se till att ni äger er data och kan använda den i andra system, till exempel i en dashboard eller i kundutskick.
  • Att inte involvera dem som använder systemet. Personalen och kontoret vet bäst var det skaver i vardagen.

Hur väljer ni? Fem frågor att ställa

  • Vad gör ni som ingen annan gör? Det är där ett eget system ger mest.
  • Var sker manuellt dubbelarbete i dag? Varje kalkylblad och varje kopiering mellan system är en kandidat för en modul.
  • Fungerar ert nuvarande system bra för grunden? Om ja – behåll det och bygg runt det.
  • Har systemet ett API? Det avgör hur enkelt det är att koppla på egna moduler.
  • Hur ser verksamheten ut om två år? Välj en lösning som kan växa med er.

Vanliga frågor

Bra att veta om val av system

Har du en fråga som inte finns här? Hör av dig så svarar vi snabbt.

Är ett skräddarsytt system alltid dyrare än ett standardsystem?
Inte nödvändigtvis över tid. Ett standardsystem har låg startkostnad men löpande avgifter, och luckorna fylls ofta med manuellt arbete. Ni får en offert efter era behov – kostnadsfritt och utan förpliktelse.
Kan vi behålla vårt affärssystem och ändå bygga eget?
Ja, det är ofta det bästa. Vi bygger egna moduler som kopplas via API till ert affärssystem, till exempel Timewave, Tengella, Fortnox eller Visma.
Vad händer om vi vill byta affärssystem senare?
Modulerna är kopplade via API, så de kan i regel kopplas om till ett nytt system utan att byggas om från början.
