Påminnis – automatiska påminnelser för obetalda fakturor

Påminnis är ett system från Kela group som automatiskt påminner era kunder om obetalda fakturor via mejl och sms. Ni väljer dagar och tider för utskicken, kunden får tydliga betalningsinstruktioner och ni slipper jaga pengar för hand. Resultatet är bättre likviditet – utan att någon på kontoret lyfter ett finger.

Boka möte → Få en offert

Vad är Påminnis?

Påminnis är ett system för betalningspåminnelser. Det jagar obetalda fakturor åt er genom att skicka påminnelser till kunden via mejl och sms – automatiskt, på de dagar och tider ni har valt. Ingen på kontoret behöver hålla koll på vilka fakturor som har blivit liggande.

Påminnis är kopplat via API till ert affärssystem, där fakturorna redan finns. Ni behöver alltså inte föra över listor eller byta faktureringssystem. Påminnis är en av Kela groups färdiga moduler och passar lika bra som en första automation som ihop med ett helt affärssystem.

Vem passar Påminnis för?

Påminnis passar företag som skickar många fakturor och vill slippa jaga betalningar för hand, till exempel städbolag och andra servicebolag. Den passar särskilt bra om ni:

  • har någon på kontoret som i dag följer upp obetalda fakturor manuellt
  • vill ha bättre likviditet utan att belasta relationen till kunden
  • redan fakturerar från Fortnox, Visma, Timewave eller Tengella
  • vill börja automatisera administrationen med en avgränsad modul

Vill ni se fler exempel på vad som går att automatisera i administrationen finns vår sida om att bygga automationer.

Vad det ger

Vad ger Påminnis ert företag?

Mer tid

Att jaga obetalda fakturor är ett typiskt onödigt arbete. Med Påminnis sköts det automatiskt, så att ingen på kontoret behöver ringa eller mejla om betalningar.

Färre missar

Ingen faktura glöms bort för att någon hade för mycket annat. Påminnelserna går ut enligt de regler ni har satt, varje gång.

Bättre likviditet

Pengarna kommer in utan att relationen till kunden blir lidande – påminnelserna är vänliga och betalningsinstruktionerna tydliga.

Vilka system kan Påminnis kopplas till?

Påminnis kopplas via API till det affärssystem ni redan använder. Ni byter ingenting – Påminnis börjar bara arbeta mot samma data som resten av verksamheten. Kela group har färdiga kopplingar mot bland annat:

  • Timewave
  • Tengella
  • Fortnox
  • Visma
  • Andra system med öppet API

Läs mer om hur kopplingarna fungerar på vår sida om integrationer.

Vad är Påminnis?
Påminnis är ett system från Kela group som automatiskt påminner era kunder om obetalda fakturor via mejl och sms. Det ger bättre likviditet utan manuellt arbete.
Skickar Påminnis påminnelser via både mejl och sms?
Ja. Påminnelserna går ut via både mejl och sms, automatiskt.
Bestämmer vi själva när påminnelserna skickas?
Ja. Ni väljer dagar och tider för utskicken, och påminnelserna innehåller tydliga, trevliga betalningsinstruktioner.
Fungerar Påminnis med Fortnox?
Ja. Påminnis kopplas via API till Fortnox, och även till Timewave, Tengella och Visma. Hos Stodona går fakturorna via Fortnox.
Vad kostar Påminnis?
Det beror på vilka funktioner, regler och kopplingar ni behöver. Ni får en offert efter era behov – kostnadsfritt och utan förpliktelse – och det går att delbetala på upp till 2–3 år. Få en offert eller boka ett möte.
