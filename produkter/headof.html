Headof – dashboard live mot ert affärssystem

Headof är en dashboard från Kela group som visar hela verksamheten live, kopplad via API till ert affärssystem. Försäljning, timmar, bokningar, avbokningar, personalrapporter och era viktigaste nyckeltal samlas på ett ställe. Den passar företag som vill ha full koll utan att sammanställa siffror i Excel, och den skräddarsys efter den data ni vill se.

Vad är Headof?

Headof är en dashboard för ledning och kontor som hämtar data direkt från ert affärssystem och visar den live. Ni slipper exportera, klistra in och räkna själva – siffrorna finns där när ni öppnar Headof.

Headof är en av Kela groups färdiga moduler. Den fungerar på egen hand, men blir som mest användbar tillsammans med de andra modulerna. När bokningar från Bokis och tid från Personalapp hamnar i affärssystemet syns de också i Headof.

Många företag följer i dag sina nyckeltal i Excel eller i huvudet. Headof ersätter det med en vy som alltid är uppdaterad och som visar just det ni behöver för att styra verksamheten.

Del av helheten

Tillsammans med Kelas andra moduler blir Headof platsen där allt som händer i verksamheten syns.

Vem passar Headof för?

Headof passar företag som redan har sin data i ett affärssystem men saknar en enkel överblick. Typiska tecken på att det är dags:

  • Nyckeltalen finns i Excel eller i huvudet på någon
  • Någon lägger tid varje vecka på att ta fram rapporter för hand
  • Försäljning, timmar och bokningar ligger i olika vyer eller system
  • Ledningen vill se läget utan att behöva fråga kontoret

Headof används i dag i städbranschen, men eftersom den skräddarsys efter den data ni vill se fungerar den även för andra verksamheter. Vi börjar med en kostnadsfri kartläggning där vi går igenom vilka siffror som är viktigast för er.

Vilka system fungerar Headof med?

Headof kopplas via API till ert affärssystem. Vi integrerar mot det ni redan använder, så ni behöver inte byta något:

  • Timewave
  • Tengella
  • Fortnox
  • Visma
  • Andra system med ett öppet API

Läs mer om hur kopplingarna fungerar under integrationer.

Används i skarp drift hos Stodona

Kela group kör allt vi säljer i våra egna verksamheter, bland annat städbolaget Stodona AB i Stockholm. Stodona driver sitt städbolag på Kelas system – Bokis, Chattis, Feedis, Påminnis, Headof, Personalapp och Kundapp – kopplade via API till affärssystemet. Headof är vyn där allt det syns live.

Med hela systemet på plats har Stodona fått:

  • ≈ 565 000 kr lägre kostnad per år – den löpande kostnaden gick från ca 52 000 till 5 000 kr i månaden
  • Från 4 till 1 person i administrationen
  • 3 heltidstjänster frigjorda

Siffrorna gäller Stodonas helhet, inte Headof ensam. Läs hela Stodona-caset.

Vanliga frågor

Bra att veta om Headof

Har ni en fråga som inte finns här? Hör av er så svarar vi inom 24 timmar på vardagar.

Vad är Headof?
Headof är en dashboard från Kela group som visar försäljning, timmar, bokningar, avbokningar, personalrapporter och era viktigaste nyckeltal live, direkt från ert affärssystem.
Vilka affärssystem fungerar Headof med?
Headof kopplas via API till ert affärssystem, till exempel Timewave, Tengella, Fortnox, Visma, Shopify och WordPress. Har ert system ett öppet API kan vi oftast koppla mot det också.
Måste vi byta affärssystem?
Nej. Vi integrerar mot det ni redan använder – ni byter ingenting, och affärssystemet är fortsatt källan till all data.
Kan vi välja vilka nyckeltal som visas?
Ja. Headof skräddarsys efter den data ni vill se, och kan byggas ut med fler nyckeltal längre fram.
Vad kostar Headof?
Ni får en offert efter era behov – kostnadsfritt och utan förpliktelse. Delbetalning på upp till 2–3 år är möjlig. Få en offert eller boka ett möte.
